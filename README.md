# Social Media Project

This is my first social media application, built using **Laravel**, **React**, and **Inertia.js**. As promised in my last repository, I’ve now started a social media project to enhance my full-stack development skills.

## Key Features

- **Authentication System**
  - Custom-built sign-up and sign-in functionality from scratch (without using external libraries).

- **User Profile Management**
  - Dedicated profile page.
  - Update profile information.
  - Display user posts.

- **Post Management**
  - Create, edit, and delete posts.
  - Display posts dynamically on the user's dashboard.

## Upcoming Features

- **Comments**
  - Users will be able to add, edit, and delete comments on posts.

- **Liking Posts**
  - Implementing a system for users to like/unlike posts.

## Technologies Used

- **Laravel**: Backend framework for routing, database management, and API handling.
- **React**: Frontend framework for building dynamic user interfaces.
- **Inertia.js**: Bridges the gap between Laravel and React for seamless SPA-like behavior.
